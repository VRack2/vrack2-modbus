**Виртуальное ведомое Modbus RTU устройство** — банк катушек (`coils`), дискретных входов (`discrete`) и holding-регистров (`holding`) поверх портов `buffer`.

Нужен как **стенд** для тестов и лабораторных сервисов: заменяет реальное устройство без железа. Значения банка задаются экшенами, поэтому проверки получаются детерминированными.

## Подключение

Устройство работает через байтовые порты `buffer`, а не через вход `bus`:

- снаружи к нему стучится TCP-клиент — это `vrack2-net.ConverterVirtual`, который принимает соединение и превращает его в порты `buffer`;
- мастера (`UniversalDI`, `UniversalDO`, `Example1` и любые другие `DeviceRTU`-устройства) ходят к стенду по шине `vrack2-net.ConverterBus`, подключённой к тому же порту `ConverterVirtual`.

Типичный стенд (см. `service-examples/rtu-lab.json`):

```
Bus.dev1 -> UDI.bus        ConverterBus (мастер) --TCP--> ConverterVirtual (порт host:port)
                           Virt.buffer -> Slave.buffer
                           Slave.buffer -> Virt.buffer
```

## Поддерживаемые функции

| Код | Функция | Область |
|---|---|---|
| `0x01` | READ_COILS | `coils` |
| `0x02` | READ_DISCRETE_INPUTS | `discrete` |
| `0x03` / `0x04` | READ HOLDING / INPUT REGISTERS | `holding` |
| `0x05` / `0x0F` | WRITE COIL(S) | `coils` |
| `0x06` / `0x10` | WRITE REGISTERS | `holding` |

- Битовые области (`coils`, `discrete`) хранят только `0`/`1`; при упаковке в ответ бит `0` байта соответствует запрошенному начальному адресу — как в реальном Modbus.
- Неизвестные адреса отдают нули, неизвестная функция — исключение `0x01`, неверный размер данных — исключение `0x03`.
- Кадры с неверным CRC отбрасываются с ошибкой `V2MODBUS_SLAVE_BAD_FRAME` и счётчиком `crcErrors`.
- Кадры чужого адреса молча игнорируются (шина RS485).

## Экшены

| Экшен | Параметры | Описание |
|---|---|---|
| `set` | `area` (`coils`/`discrete`/`holding`), `address`, `value` | Записать значение в банк вручную |
| `read` | `area`, `from`, `count` | Прочитать значения банка |

Пример (поднять `di1` и `di3` для `UniversalDI` — в битовых областях значение это `0`/`1` одного адреса):

```json
{ "area": "discrete", "address": 0, "value": 1 }   // di1 (адрес 0)
{ "area": "discrete", "address": 2, "value": 1 }   // di3 (адрес 2)
```

## Shares

| Ключ | Описание |
|---|---|
| `requests` | Всего обработано запросов |
| `writes` | Всего записей в банк (по шине и через экшены) |
| `crcErrors` | Кадры с неверным CRC |
| `coils` / `discrete` / `holding` | Снимок банка: ключ — адрес в hex (`0x0000`), значение |

## Опции

| Опция | По умолчанию | Описание |
|---|---|---|
| `address` | `1` | Modbus-адрес, на который стенд отвечает |
| `exceptionFuncs` | `[]` | Коды функций, на которые стенд отвечает исключением `0x01` (имитация неподдерживаемой функции — запрос при этом засчитывается) |
| `debug` | `false` | Логировать принятые и отправленные кадры |

## Замечания

- Одновременно обслуживается один TCP-клиент (ограничение `ConverterVirtual`).
- Незавершённый кадр сбрасывается таймером 500 мс — обрывки не копятся.
- Экшен `set` для `coils`/`discrete` приводит значение к `0`/`1`.
