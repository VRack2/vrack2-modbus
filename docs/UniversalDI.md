Устройство предназначено для опроса **дискретных входов (DI)** удалённого Modbus-устройства по протоколу **Modbus RTU** с использованием функции **READ_DISCRETE_INPUTS (0x02)**.

Поддерживает до **64 входов**, автоматически создаёт соответствующее количество выходных портов и оптимизировано для промышленного использования.

- Каждый порт выдаёт значение `0` или `1` в соответствии с состоянием соответствующего дискретного входа.
- Нумерация соответствует Modbus: **бит 0 первого байта → `di1`**, **бит 1 → `di2`**, и т.д.

## Логика работы

1. При поступлении на вход `bus` провайдера **TCPProvider** (от `vrack2-net.ConverterBus`) выполняется Modbus-запрос `0x02` с количеством запрашиваемых битов = `сountDI`.
2. Полученный буфер разбивается на байты.
3. Каждый байт разбирается **побитно**, начиная с младшего бита (`bit 0`).
4. Значения обновляются в `shares.di` и передаются в соответствующие выходные порты **только при изменении**, если не включён режим `eachGate`.

## Опции

| Опция | По умолчанию | Описание |
|---|---|---|
| `address` | `1` | Modbus-адрес устройства |
| `сountDI` | `8` | Количество DI-портов (1..64). **Внимание:** первая буква — кириллическая `с`, опция латиницей `countDI` не существует |
| `eachGate` | `false` | `true` — пуш в выходы при каждом опросе, `false` — только при изменении |
| `timeout` | `700` | Таймаут Modbus-запроса, мс |
| `offTimeout` | `30000` | Таймаут неприхода провайдера, после которого устройство считается offline |

## Замечания

- Последний байт при `сountDI` не кратном 8 обрабатывается по количеству значимых битов: лишние биты ответа игнорируются.
- Если ведомый отвечает исключением (`func | 0x80`), `ModbusRTU.parseResponse` бросает `V2MODBUS_EXCEPTION` (с кодом и адресом), цикл `update` падает и устройство уходит в `offline`.
- Стенд для проверки без железа — `ModbusRTUSlave` (банк дискретных входов ставится экшеном `set` с `area: "discrete"`).
